# #19 — Replace repository sync scripts with one CLI configuration

## Ask

Migrate all three current tracker clients to the standalone CLI once its sync is ready.

## Status

Not started. Current clients share a Python engine in the Staffeto wiki; even Cardstock's own shim depends on that external checkout.

## Rationale

Use the same installed CLI for Cardstock, Designer and Website without copying scripts or relying on local checkout paths.

## Evidence

Clients: backlog/board.json; Staffeto delivery/designer/board.json and delivery/website/board.json. Differences include workflow rules, tag aliases, audience mappings and seeds.

## Residuals

Preserve each board's vocabulary, mappings and validation rules. Support importing existing configuration with explicit diagnostics. Validate round trips on snapshots from all three boards, document installation and recovery, and retire shims only after parity. No need to add non-Cardstock providers in this migration.
