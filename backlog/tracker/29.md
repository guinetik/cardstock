# #29 — Download card as markdown

## Ask

Currently a card cannot be downloaded when viewing/editing. create a new button on the card page that would allow to download the card as a markdown with its current front-matter as if we are performing a sync but just of that file, meaning it should download just as it does when we are syncing.

## Status

**Done — reviewed and accepted for deployment.** Download markdown is available beside Clone card on the full card page and modal. Downloads match CLI sync, including current frontmatter, custom fields, body, and saved comments, without changing stored card data. The button waits for autosaves and prompts users to save or cancel unfinished drafts. Access is limited to members who can view the project.

Validation: production build, TypeScript, and changed-file lint passed, along with three save-coordination unit tests and four browser tests covering export parity, pending and failed saves, modal downloads, and access restrictions. Mobile layout reviewed; user confirmed the feature works.
