# #13 — Install Cardstock from npm without cloning the app

## Ask

Package the CLI independently and use public npm with GitHub OIDC releases.

## Status

Published @guinetik/cardstock-cli 0.1.1 on 2026-09-06. The cardstock command reports its version. Bun workspaces contain a private core and a Node CLI; the Next.js app remains at the root. CI verifies an installed tarball before publishing.

## Rationale

Install the CLI as its own npm package while keeping its shared code and website in one repository.

## Evidence

Commits af669f3 and 6c65381; tag cli-v0.1.1. GitHub run https://github.com/guinetik/cardstock/actions/runs/34011143250 passed. Public npm npx invocation returned 0.1.1.
