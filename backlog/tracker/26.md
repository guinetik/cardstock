# #26 — A table view of cards, like a GitHub Projects list

## Ask

Not a single verbatim request — a pattern across the whole [[2026-09-08]] call. Hap repeatedly lost his place navigating lanes to find one card or one status:

> Hap: *"Can you guys… where is this?"* / *"Where is it?"* — asked at least four separate times hunting for a specific card or lane.

> Hap: *"I feel like I have to go through all the boards and run through each and every one of these things to figure out where the fire is."*

> Hap: *"Where was the priority? Later, next? Where was the Needs Hap? We don't have anything that needs Hap right now."*

Groomed on the same call into a concrete gap: the board only offers the kanban/lane view, and there is no flat, sortable, filterable list of cards the way GitHub Projects (or a plain table) offers — something that answers "find me this one card" or "sort everything by X" without lane-hopping.

## Status

**Done — reviewed and accepted for deployment.** The board now offers Kanban and Table views in the header's labeled View controls, beside the Actions buttons. The table shares the board filters and live updates, sorts by card fields without changing shared ranks, opens card detail sheets, and includes watch controls. Both Paper themes and narrow screens are supported.

Validation: production build and TypeScript passed; 37 sorting/filter unit tests and 10 browser checks passed. The final toolbar placement was checked on desktop and mobile.

## Rationale

This is the navigation half of Hap's earlier "customer health dashboard" pitch — the concrete gap under it turned out to be a missing list/table surface, not a bespoke visualization. It sits alongside the filter work in [[9]] and [[25]]: a table view is what makes filters (priority, overdue, forgotten, assignee) actually useful for finding one thing fast, rather than only narrowing a kanban lane.

## Residuals

- Whether this replaces or supplements the Epic Cockpit / Timeline as the "high-level" view Hap was reaching for is still open.
- Per-board lane customization to match Sanjay's Staffeto delivery-gate process (creds, requirements gathering, discovery, dev, testing, sign-off) came up in the same discussion as a related but separate gap — not filed yet.
