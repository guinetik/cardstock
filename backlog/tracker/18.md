# #18 — Sync Markdown and board edits without losing either side

## Ask

Apply a conflict-aware bidirectional sync plan with safe recovery.

## Status

Not started. Depends on #17's planner and #16's conditional write API.

## Rationale

Let local issue edits and board changes meet without relying on a fragile import/export order.

## Evidence

Audit on 2026-09-06 found client guidance says import then export with protected priority, while current ETL takes priority from files and recommends export then import. Neither ordering alone protects concurrent edits.

## Residuals

Compare against the saved baseline. Report conflicting field changes; do not silently choose a winner. Preserve unknown frontmatter and formatting, separate remote identity from filenames, never infer deletion from a missing file, use atomic file writes and a progress journal, and advance baselines only for verified outcomes. Test concurrent edits and interrupted runs.
