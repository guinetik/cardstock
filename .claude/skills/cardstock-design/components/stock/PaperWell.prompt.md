Stock cut *into* the desk rather than laid on it — an inset tray for things not yet filed.

```jsx
<PaperWell style={{ padding: "1rem" }}>Nothing here yet.</PaperWell>
```

Use it for drop zones, the inbox drawer, and anywhere the page should read as a recess. Do not use it for content that has been filed — that is a `PaperCard`.
