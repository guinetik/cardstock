Use `Stamp` for the rubber stamp in a folder's margin — the filed card count, in the red pen, tilted 4°.

```jsx
<Stamp>13 cards<br />filed</Stamp>
<Stamp faint>nothing<br />filed</Stamp>
```

One stamp per page. It and a card in hand are the only tilted things in the product, so a second stamp costs the first its meaning. `faint` is the grey version for an empty folder.
