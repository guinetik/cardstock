Use `EpicLabel` wherever a card names its epic — the book glyph plus the epic's own name, in grey at 11px.

```jsx
<EpicLabel name="Onboarding" />
<EpicLabel name="Onboarding" compact />
```

`compact` is the 9px uppercase form used in dense timeline rows. The epic is source-owned text, so never abbreviate or re-case it beyond that variant.
